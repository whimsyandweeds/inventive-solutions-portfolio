# Inventive Solutions — Portfolio Pipeline

Snap-scroll portfolio site (scenery edition).

## Open it
Open `index.html` in a browser. No build step.

Put photos in `images/`:
- `hero.jpg` cover
- `pipeline.jpg` overview diagram
- `whimsy.jpg` greenhouse
- `avi.jpg` neon ops
- `docket.jpg` courthouse bronze
- `sophie.jpg` container yard

If an image is missing, that block just shows the grey background.

## Edit
- Colors and type: `:root` at the top of `index.html`
- Each section is labeled `PAGE 1` … `PAGE 7` in HTML comments

## GitHub Pages
Repo Settings → Pages → Deploy from branch → `main` / root
Then the site is at:
https://whimsyandweeds.github.io/inventive-solutions-portfolio/
